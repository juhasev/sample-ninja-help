### Multiple compensation tables by a data variable

This feature allows you to define multiple compensation tables based on a radio data variable. Using this feature is completely optional.

For example, in medical panels, compensation can now vary by **specialty** without requiring separate sub-panels for each audience segment.

**Key benefits**

- Configure compensation more precisely by respondent group
- Support specialized audiences with different incentive requirements
- Simplify compensation management

> **IMPORTANT:** You must ensure that each panelist has the data variable for which compensation is defined. You can do a quick check under **Data Variables** (click the blue stat button and add a subpanel filter).

**Adding or removing an option later**

When you edit the data variable used here, Sample Ninja warns you and names every sub panel that uses it for compensation. After saving the variable, open each of those sub panels and set an amount for the new option in **Sub Panels -> Manage -> Settings -> COMPENSATION**.

> **IMPORTANT** The new option applies to **new projects only**. Projects that already exist keep the compensation they were saved with and will have no amount for the new option, so a panelist who answers with it earns nothing for that project. Review any project that is still running before you add an option, and use **Reset** on the project's **Compensation** tab if that project should use the sub panel's current table.

> Removing an option does not change the compensation already saved on existing projects either. Their historical amounts stay in place so past and in-flight participation stays consistent.
