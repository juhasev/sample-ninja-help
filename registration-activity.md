## Registration activity

This list view provides you ability to see what happen during the registration session, review reject and also new confirmed panelist.

### Status

Each row shows the furthest step the registration reached:

- **Started**: the person opened the registration survey and started answering.
- **Completed**: the survey was submitted, but the email address is not confirmed yet.
- **ID pending**: the ID check is switched on for this registration survey. The person confirmed their email address, or registered without an email confirmation step, but the ID check is not approved yet. They may still be on the ID check page, they may have left it, or the check may need another try. The registration becomes **Confirmed** only when the ID check is approved.
- **ID declined**: the ID check was declined.
- **Confirmed**: the registration is finished. When the ID check is on, this means the ID check was approved.
- **Rejected**: a security check rejected the registration.
- **Disqualified**: an answer to a registration question disqualified the person.

Use the filter button to show one status at a time. A person shown as **ID pending** can finish the ID check later by clicking the confirmation link in their email again.

> Click the edit button on each row to instantly view the panelist profile. This button is only available if the panelist was actually created which means passing all the security tests.

> Use the reload button on the top right to refresh the view with the latest data.
